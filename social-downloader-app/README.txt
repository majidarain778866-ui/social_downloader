A blazing-fast, modern, glassmorphic social video and audio downloader for WordPress.

== Description ==

Social Video Downloader Pro allows you to embed a professional, responsive video downloader on any WordPress post or page using the simple shortcode:

`[social_downloader]`

Supports downloading high-quality 1080p/720p MP4 videos and 320kbps MP3 audio from over 40 platforms, including:
* Facebook (Reels, Watch, Videos)
* TikTok (HD videos without watermark)
* Instagram (Reels, Posts, Stories, Carousels)
* YouTube (Shorts & Videos)
* X / Twitter (HD Videos & GIFs)
* Pinterest (Idea Pins & Videos)
* Reddit, TeraBox, Vimeo, and more!

== Installation ==

1. Download `social-downloader-app.zip`.
2. Go to your WordPress Admin Dashboard -> **Plugins** -> **Add New** -> **Upload Plugin**.
3. Choose `social-downloader-app.zip` and click **Install Now**.
4. Click **Activate Plugin**.
5. Go to **Social Downloader** in your WordPress admin menu to review or customize your API endpoint and colors.
6. Add `[social_downloader]` to any page or post.

== Shortcodes ==

* Default Downloader:
  `[social_downloader]`

* Custom Title & Subtitle:
  `[social_downloader title="TikTok Video Downloader" subtitle="Download TikTok videos without watermark in HD"]`

* Dedicated Platform Page:
  `[social_downloader title="Facebook Video Downloader" platform="facebook"]`
  `[social_downloader title="Instagram Reels Downloader" platform="instagram"]`
